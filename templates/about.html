About

UH OH CUSTOMS made by Sc00by

This is a simple web application that allows users to track their League of Legends games and statistics. The application is built using Flask, a Python web framework, and SQLite, a lightweight database engine.

The application uses the Riot Games API to retrieve data about League of Legends champions, items, and summoner spells. The API is rate-limited to prevent abuse and ensure fair usage by all developers.
